AIO Feeder — Web Flasher

Flash the hub and node firmware straight from the browser. No IDE, no drivers on Windows/macOS.

Requirements: Chrome or Edge on desktop (Web Serial), a USB data cable, and the board in download mode. Close any program holding the serial port (serial monitor, Arduino IDE). Flashing erases the targeted app region — keep the device on stable power until the write finishes.

Hub

Waveshare ESP32-S3-Touch-LCD-4.3B — schedules, calibration, logs. Hold BOOT, plug USB, release.

Chip: ESP32-S3Manifest: hub/manifest.json
Web Serial unavailable — open in desktop Chrome/Edge over HTTPS.

Node — ESP32-C3

ESP32-C3 SuperMini + DS3231 + relay + 12 V solenoid. Hold BOOT, plug USB, release.

Chip: ESP32-C3Manifest: node-esp32c3/manifest.json
Web Serial unavailable — open in desktop Chrome/Edge over HTTPS.

Node — ESP8266

ESP-12F class module + DS3231 + relay + 12 V solenoid. Pull GPIO0 low while resetting.

Chip: ESP8266Manifest: node-esp8266/manifest.json
Web Serial unavailable — open in desktop Chrome/Edge over HTTPS.

How to flash

  1. Plug the board in with a data USB cable (charge-only cables will not enumerate a serial port).
  2. Put the board in download mode: hold BOOT (or tie GPIO0 low) while connecting USB.
  3. Press the install button for your board, pick its serial port, and follow the prompts.
  4. First install or recovery: allow the installer to erase the device when asked.
  5. When the write finishes, power-cycle the board — it boots the new firmware.
